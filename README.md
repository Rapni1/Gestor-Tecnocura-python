# Sistema de Gestión TecnoCura v2.0

Un sistema CRUD de consola desarrollado en Python para la gestión de órdenes de reparación de dispositivos electrónicos. 

## Características
- **Registro y control:** Almacena nombres de clientes, modelos de celular y presupuestos.
- **Persistencia de datos:** Sincronización automática con archivos de texto local (`.txt`).
- **Generación de recibos:** Creación dinámica de tickets de entrega para clientes.
- **Buscador integrado:** Filtro de clientes insensible a mayúsculas/minúsculas.
- **Cálculo financiero:** Proyección automática de ganancias de equipos en taller.
- **Manejo de excepciones:** Prevención de caídas del sistema por inputs inválidos.

## Tecnologías
- Python 3 (Estructuras de datos, I/O de archivos, control de flujo, funciones).
